  • MISSION 1 — Déploiement de GLPI sur Windows Server (M2L.LOC)

    Contexte

    Dans le cadre d'un projet de BTS SIO réalisé en binôme, nous devions installer et configurer de zéro un outil de gestion de parc informatique et de helpdesk (GLPI) sur un serveur Windows Server, accessible via le nom de domaine interne M2L.LOC.

    Démarche

    Installation des prérequis (IIS, PHP, MySQL/MariaDB), téléchargement et déploiement de GLPI sur le serveur, configuration de la base de données et du DNS interne pour l'accès via M2L.LOC, puis paramétrage de l'application : création des comptes utilisateurs, intégration du parc matériel et mise en place du système de tickets.

    Résultats / Livrables

    Un serveur GLPI pleinement fonctionnel et accessible en interne, accompagné d'une documentation détaillant la procédure d'installation ainsi que des captures d'écran de la configuration finale.

    Compétences mobilisées

    Administrer les accès et les services applicatifs, déployer et exploiter un service, mettre en production une solution applicative, travailler en mode collaboratif (binôme).

  • MISSION 2 — Développement d'un site web avec base de données

    Contexte

    Dans le cadre d'un projet imposé par notre professeur, réalisé en binôme, nous devions concevoir et développer un site web dynamique intégrant une base de données.

    Démarche

    Conception et développement d'un site en HTML/CSS et PHP, avec mise en place d'une base de données SQL. Le site intègre un système de gestion d'utilisateurs (inscription/connexion), un catalogue de produits, ainsi qu'un CRUD complet permettant l'ajout, la modification et la suppression de données.

    Résultats / Livrables

    Un site web fonctionnel en ligne accompagné d'un rapport / compte-rendu détaillant les choix techniques et la procédure de développement.

    Compétences mobilisées

    Gérer une base de données, travailler en mode collaboratif (binôme).
